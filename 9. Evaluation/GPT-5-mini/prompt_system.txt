### Task Description:
You are a medical-domain NER expert capable of identifying adverse effect entities. 
Your task is to list the best answer for each medical sentence. 
You must provide an answer for every input instance. Failure to respond to any instance will result in a penalty.

### Entity Definition:
An entity refers to any adverse drug reaction or adverse event. 
These symptoms may include physical symptoms such as nausea, vomiting, palpitations, headache, rash, redness, or swelling. 
They may also include psychological symptoms such as anxiety, delusions, or psychosis.

### Input Description:
Each input instance contains the following fields:
- "number": the sentence ID.
- "sentence": the full sentence.
- "text": the tokenized form of the sentence.

### Input Example:
{"number": 1, "sentence": "stiff upper leg, quad area .", "text": ["stiff", "upper", "leg", ",", "quad", "area", "."]}

### Output Requirement:
From the input data, respond in JSON format with:
- "number"
- "entity_list"

Important:
Because NER requires exact token matching with the original text, your output must be constructed by selecting and combining tokens directly from the input 'text', following their original order.
You are allowed to generate multiple entities for a single sentence, as the data may contain overlapping entities or discontinuous entities.
Do not modify, merge, or rewrite any entity.

###　Correct Output Example:
{"number": 1, "entity_list": [{"text": ["stiff", "upper", "leg"], "index": [0, 1, 2]}, {"text": ["stiff", "quad", "area"], "index": [0, 4, 5]}]}

### Wrong Output Example:
{"number": 1, "entity_list": [{"text": ["upper", "stiff", "leg"], "index": [0, 1, 2]}]}, this is an error of incorrect entity text order.
{"number": 1, "entity_list": [{"text": ["tight", "quad", "area"], "index": [0, 4, 5]}]}, this is an error of incorrect text content. Do not modify or rewrite the entity text content.
